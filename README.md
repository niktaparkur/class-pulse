# Class Pulse - Интерактивная Система Опросов для Образования

Class Pulse - это веб-приложение на Flask, предназначенное для проведения быстрых опросов ("Пульс класса") и сбора обратной связи от студентов в режиме реального времени во время занятий.

## Основные Возможности

*   **Два типа опросов:**
    *   **Пульс Класса:** Быстрый опрос с заранее заданными вариантами для оценки общего настроения или понимания (например, "Как вы себя чувствуете перед уроком?").
    *   **Обратная Связь:** Более детальный опрос с несколькими вопросами разных типов (шкала, открытый текст) для сбора развернутых мнений.
*   **Панель Учителя:**
    *   Запуск новых опросов (стандартных, кастомных или на основе шаблонов).
    *   Просмотр активных и завершенных опросов.
    *   Отображение результатов опросов в реальном времени с использованием графиков (для шкальных ответов) и списков (для текстовых).
    *   Генерация уникальной ссылки и QR-кода для каждого опроса для быстрого доступа студентов.
    *   Возможность завершать и удалять опросы.
    *   Экспорт результатов опроса в CSV-файл.
    *   Управление личными шаблонами опросов.
*   **Интерфейс Студента:**
    *   Простой и понятный интерфейс для ответа на вопросы опроса.
    *   Возможность анонимного ответа или указания своего имени.
    *   Защита от повторного голосования с одного устройства (через cookies).
*   **Панель Суперадмина:**
    *   Управление учетными записями учителей (создание, редактирование, активация/деактивация, удаление).
    *   Просмотр всех опросов, созданных всеми учителями в системе.
    *   Управление общими (системными) шаблонами опросов, доступными для всех учителей.
    *   (В перспективе) Модерация контента, просмотр статистики.
*   **Технологии:**
    *   Python, Flask, Flask-SQLAlchemy, Flask-Login, Flask-SocketIO, Flask-Migrate.
    *   База данных: SQLite (по умолчанию, легко заменяема).
    *   Фронтенд: HTML, CSS, JavaScript (ванильный JS, Chart.js для графиков).
    *   QR-коды генерируются с помощью библиотеки `qrcode`.
    *   Модерация текстовых ответов с использованием `better-profanity` и кастомных списков.


## Установка и Запуск

1.  **Клонировать репозиторий (если он есть):**
    ```bash
    git clone https://github.com/niktaparkur/class-pulse.git
    cd class_pulse_project_root
    ```

2.  **Создать и активировать виртуальное окружение:**
    ```bash
    python -m venv venv
    # Windows
    venv\Scripts\activate
    # macOS/Linux
    source venv/bin/activate
    ```

3.  **Установить зависимости:**
    ```bash
    pip install -r requirements.txt
    ```

4.  **Настроить переменные окружения:**
    *   Скопируйте `.env.example` в `.env`.
    *   Откройте `.env` и заполните необходимые значения:
        *   `SECRET_KEY`: Сгенерируйте случайный ключ (например, `python -c 'import secrets; print(secrets.token_hex(16))'`).
        *   `DATABASE_URL`: По умолчанию `sqlite:///classpulse.db` (относительно корня проекта, где `run.py`). Можно изменить на URL для PostgreSQL, MySQL и т.д.
        *   `ADMIN_USER`: Логин для учителя по умолчанию (например, `admin`).
        *   `ADMIN_PASS`: Пароль для учителя по умолчанию. **Обязательно смените!**
        *   `SUPERADMIN_USER`: Логин для суперадмина (например, `superadmin`).
        *   `SUPERADMIN_PASS`: Пароль для суперадмина. **Обязательно установите и смените!**
        *   `FLASK_CONFIG`: `development` (по умолчанию) или `production`.
        *   `FLASK_DEBUG`: `True` для разработки, `False` для продакшена.
        *   `SERVER_NAME`: (Опционально, для работы с куками на разных поддоменах или за прокси, например `localhost:5000` или `yourdomain.com`).
        *   `PUBLIC_BASE_URL`: Полный публичный URL вашего приложения (например, `http://localhost:5000` или `https://yourdomain.com`). Используется для генерации ссылок в QR-кодах и уведомлениях.

5.  **Инициализировать базу данных и создать пользователей:**
    *   При первом запуске `python run.py` база данных должна создаться автоматически, включая таблицы и пользователей по умолчанию (суперадмин и учитель 'admin').
    *   Если вы используете Flask-Migrate (рекомендуется):
        ```bash
        # Установить FLASK_APP (если еще не установлено глобально)
        # Windows: set FLASK_APP=run.py
        # macOS/Linux: export FLASK_APP=run.py
        # или FLASK_APP="app:create_app()"

        flask db init  # Только один раз для проекта, если папки migrations нет
        flask db migrate -m "Initial migration" # Или описание изменений
        flask db upgrade # Применяет миграции к БД
        ```
        После этого можно запустить `python run.py`, и `setup_database_and_admin` (вызываемая из `run.py`) проверит/создаст пользователей.

6.  **Запустить приложение:**
    ```bash
    python run.py
    ```
    Приложение будет доступно по адресу `http://localhost:5000` (или на порту, указанном в `.env`).

## Использование

*   **Суперадмин:** Заходит под учетными данными суперадмина. Может управлять учителями, просматривать все опросы, управлять системными шаблонами. URL: `/superadmin/`
*   **Учитель:** Заходит под своей учетной записью. Может создавать опросы, просматривать результаты своих опросов, управлять своими шаблонами. URL: `/teacher/` (или `/`)
*   **Студент:** Переходит по ссылке или QR-коду, предоставленному учителем, для участия в опросе.
